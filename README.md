## Governing principles

1. CF-02 owns support cases, queues, SLA timers, case communications, appeal dossiers and implementation reconciliation.
2. CF-02 does not replace account/verification/moderation/clinical/payment/security/messaging/marketplace authorities.
3. Sensitive actions are server-side authorized against current identity/capability/object/field/purpose/consent/state/record version.
4. Native owner commands are required for cross-domain decisions/mutations; foreign-table direct writes are prohibited.
5. Activation remains fail-closed until Founder-approved gates/evidence pass.
