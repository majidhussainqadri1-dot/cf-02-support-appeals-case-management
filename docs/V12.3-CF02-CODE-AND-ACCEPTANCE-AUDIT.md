## Security and privacy contracts retained

- File 00 is the sole canonical identity/authorization source; WordPress role labels alone grant no case authority.
- Support agents obtain case-, purpose-, field-, time- and assignment-scoped access only.
- Sensitive medical, identity, payment and other native-domain data remain with their canonical owners.
- The guest portal accepts only the allowlisted `GuestIntakePolicy` categories; no case is created before authenticated step-up and explicit confirmation.
- The guest continuation token is authenticated encrypted, bounded to 10 minutes and stored only in same-tab session storage. It is never placed in a URL/query, analytics event, or long-term browser cache. Failure of browser storage means sign in and create a new case.
- A guest emergency diversion must show a safe explanation, not pretend to provide emergency clinical care or to have created a case.
- Final appeal, refund, clinical, safety, moderation and identity decisions must never be auto-executed by CF-02 helper functions.
- Donor status, sponsorship, ranking, reach and popularity cannot determine triage, SLA, appeal eligibility or case outcome.
